## Purpose
The Expense Claims app is an online tool for colleagues to enter expense details and generate a form that can then be submitted for reimbursement of the value of the expenses.  
The app should be used when you have paid for items or services for activities related to company business from your own money. This expense to you can be repaid after the successful submission of an expense claim form.  
Any expenses above the threshold for that type of expense will be flagged as requiring approval from your line manager. The expense claim form will provide areas to obtain this approval.  
<br>
## User guidance
Access to the app is not restricted, you will not need to download any software or create an account. You can access the Expense Claims App using the link below:  
[Expense Claims App](https://expensesclaimapp.netlify.app/)
<br>
1. On the first screen add the information about your expenses into the fields provided. If entering an expense for milage, please provide the number of miles travelled and an expense value will automatically be calculated. 
<br><br>

![Expense input screen](/documentation/images/expenseInputScreen.png)  
**Figure 1:** First screen of the app with input fields for expense details.  
<br><br>
2. Once all fields have been completed click the ‘Add expense’ button. If you have additional expenses to add, enter the information for each expense one at a time and click ‘Add expense’ after each entry.  
3. When all expenses have been added click ‘Review expenses’ to view all expenses that have been added to the claim.
<br><br>

![Expense review screen](/documentation/images/expenseReviewScreen.png)
**Figure 2:** Review screen of two expenses with a total value and one expense requiring line manager approval.
<br><br>

4. All expenses add will be shown with warning text beneath if any expense requires your line manager’s approval. You may remove any expenses not needed or return to the previous screen to add additional expenses. When complete, click ‘View claim’.
5. Using your browser options, you can now ‘print’ this page to save a PDF version of the final claim form. This can be sent to your line manager for approval, if required, and then to the expenses team to be processed.
